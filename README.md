# Click Moment

A two-player browser game about creating insight through conversation.

## How to Play

Open `index.html` in any modern browser.

- **Player 1** moves the blue yo-yo with **WASD**
- **Player 2** moves the pink yo-yo with **Arrow keys**

The glowing elastic string between the two yo-yos represents conversation. Guide the string through floating word bubbles in the correct order to create **Click Moments**.

Complete **3 Click Moments**, then move both yo-yos to the center at the same time to win.

## Sequences

Each Click Moment requires a conversation thread such as:

1. Question → Response → Spark
2. Idea → Question → Response
3. Question → Pause → Idea

Beat the **90-second** countdown!
